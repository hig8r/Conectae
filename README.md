# Conectae — Landing page

Site institucional da agência Conecta É (@agconectae).

## Publicar no Vercel
1. Crie um repositório no GitHub chamado `Conectae`.
2. Envie o conteúdo desta pasta (Add file → Upload files).
3. No Vercel: Add New → Project → importe o repositório `Conectae` → Deploy.
   Não precisa de configuração: o Vercel publica o `index.html` direto.

## Estrutura
- `index.html` — site pronto, com animações, fontes e logo embutidos.
- `assets/conecta-logo.png` — logo / favicon.
- `source/` — código-fonte editável e comentado. Para editar, abra
  `Conecta E Landing v2.dc.html` e siga os comentários de cada seção.
  Depois de editar, gere o `index.html` de novo.
